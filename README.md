# 百合花船·教程
**「百合花船·教程」是百合研社团主管、与社区共建的服务与基础建设企划「百合花船」的项目。** 本项目（主要）通过文章与视频等媒介，给出教程和指引，帮助百合爱好者寻找信息、从 所在国家/地区 内外购买自己喜欢的二次元作品（包括其衍生产品）等，是「百合花船」企划向包括百合爱好者在内的很多人科普的阵地。其中，同名网站称「本站」。
