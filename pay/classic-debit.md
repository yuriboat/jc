支持绑定国内支付平台的万事达单标卡，都是新万事达卡。
:::

## 1. 介绍
只有2家银行在发行 完整或不完整地支持境外线上支付 且 不设年费 的Visa/旧万事达储蓄卡，那就是中国银行和中信银行。

长城跨境通国际借记卡，是**中国银行**发行的 **VISA / MasterCard 多币种外标借记卡**，下文简称“中行的卡”。

中信银行Visa外币借记卡，是**中信银行**发行的 **多币种外标借记卡** ，下文简称“中信的卡”。以前，中信银行还发行过旧万事达储蓄卡，现已停发，停发后推出了新万事达双币储蓄卡。

::: tip 注意
如果网站不支持国内发卡的全部信用卡或者除了JCB之外的信用卡，跨境通卡一般也无法使用。这可能是因为相关网站或平台「锁区」了，通过卡bin（卡号前6位）限制部分国家和地区的消费（比如ChatGPT），或者做白名单只接受当地卡（比如Apple的App Store）。不过，如果你是在日本的网站遇到这种问题，可以试试办理国内银行发行的JCB的信用卡（仅在职人士可办理），因为JCB卡很多时候可以绕过日本网站的锁区……

::: tip 以下网站/平台，中信的卡因自身原因**可能支持，可能不支持**
PayPal：看运气。如果直接绑定成功，那就可以正常使用。如果要求输入绑定验证码，那就无法绑定，因为中信的卡的账单打不出这个验证码。
:::

::: tip 听说中信以前是拒付王，我还能办吗？
经过多轮改进，中信银行大大改善了网付和线下支付的体验，给老卡OTA了3DS验证和多币种交易，成功摆脱拒付王的外号。中信的卡还是目前唯一一张能绑定Apple Pay的国内银行发行的VISA储蓄卡，比中行还给力 ~~（@中国银行）~~ 。
:::

### 1.1 优点
①是储蓄卡（不是0额度信用卡），**无法办理校园版0额度信用卡的各阶段学生 / 其他无法或不想办理信用卡的人** 都可办理；
②是多币种卡，中行的卡支持消费 19 种外币，中信的卡支持消费 8 种外币；
③不占一/二类卡额度：需要的人自然知道是什么意思。

::: tip 线下实体店刷卡时的「DCC」大坑 以及 如何避开
> DCC，全称Dynamic Currency Conversion，也就是把当地货币实时转换为你的卡片的记账货币，理论上来说是刷卡当时就转换货币，听上去好像是挺好的一个功能，但是 DCC 的汇率通常不太合算，还有手续费（储蓄卡会直接扣除，信用卡会记到账单里），至于DCC的原理，有兴趣的可以自行去了解。在绝大多数国家和地区的货币汇率相对稳定的背景下，我们完全没有必要选择同意DCC。
> DCC只存在于Visa和Mastercard的卡片中，其他卡组织没有DCC。
> **请注意，免税店用美元结算是正常的，此时不要要求用当地货币，否则反而会被DCC。**
> 在结账刷卡前，请明确与收银员说明「No DCC」「请以（当地货币）结账」。如果收银员让你选择甚至是推荐转换成人民币/美元，不要转！！刷卡后会有一个签购单，请务必阅读签购单，确保上面只印了商家当地的货币，并且没有一大段英文说货币转换的事情（有的话，说明被DCC了）！！如果签购单（收银员准备收走的那张）有货币选择，请在当地货币处打「X」（X代表你的选择，不是对勾）！！
> 如果POS机无法调整DCC设置（强制DCC）或者收银员实在不会操作，请在给收银的签购单的美元/人民币金额附近写上NO USD/NO CNY，然后再签名，同时拍照。之后，尽快向银行反馈，退回被多收的款项。
:::

### 1.2 缺点
①**先存钱，再消费：** 不如有额度的信用卡的每月一次还款（而且很多银行信用卡的外币消费都是以人民币入账，不需要另外购汇来还款）来得便捷。

②**购汇（人民币->外币）只能在北京时间每日7:00-23:00操作：** 如果要在在北京时间每日23:00到次日7:00买东西，得提前购汇，要不然有钱花不了。

**中信的卡的独占缺点是可能绑不上PayPal：**这卡能否绑定PayPal要看运气，如果直接绑定成功，那就可以正常使用；如果要求输入绑定验证码，那就无法绑定，因为中信的卡的账单打不出这个验证码。

**中行的卡的独占缺点之一是非美元预存102%：**如果你的订单不以美元交易，那么要记得存够你打算消费的金额的**102%**，消费时先冻结102%，实际扣100%，剩下的2%在「入账」后返还，详见[下文](#e1-1-扣款流程)；

**中行的卡的独占缺点之二是附近不一定有卡：** 不是每个网点都有跨境通卡可以办！如果你不在上海，请参照[下文](#_3-2-如何申请)来问各个网点；
④虽然**日本的购物网站大多都支持中行这个跨境通卡**，但海外部分商户可能不支持储蓄卡，或者出点小问题，部分行业可能不接受储蓄卡；
⑤**购汇（人民币->外币）只能在北京时间每日7:00-23:00操作：** 如果要在在北京时间每日23:00到次日7:00买东西，得提前购汇，要不然有钱花不了。

## 3. 申卡指南
### 3.1 申请前
**申请前，请确保你已满足以下条件，或者正在满足。以下条件适用于可以申领居民身份证的中国大陆地区居民，其他类型的居民等可能有不同。**
1. **年满 16 周岁，且已领取居民身份证，年龄较小（<=25）的最好是学生/准学生或有正规工作**。部分地区可能不给未满 16 周岁的客户开通手机银行，这会对使用 Visa/旧万事达 储蓄卡带来很大的不便，这意味着你需要在线下柜台购汇或存入外币现金。

2. 确定是否需要新办理对应银行的银联储蓄卡。如果有，可不用新办；如果没有，在办理 Visa/旧万事达储蓄卡的同时或之前要新办。

如果你想办理中行的卡，检查自己是否有 **中国银行** 的银联 **一类** 储蓄卡 或是 有印「**中国银行**」的**社会保障卡（社保卡）**；如有，还请检查是否可以购汇（登录「中国银行」App并登录后，点击首页「账户管理」，先确保你的卡已经绑好了（没绑的请添加），然后搜索「结汇购汇」，点击「购汇」，倒计时走完之后点下一步，点击「交易账户」，看看你的卡是否在列表里。）。如果没有中行的一类卡/社保卡，或是无法购汇，请阅读：[如何办理中国银行一类卡，或从二类升到一类？](/pay/boc-debit-extra)

如果你想办理中信的卡，中信的所有银联/运通/新万事达储蓄卡均可正常使用人民币来购汇，如果尚未持有，可以当场顺带办理，或在中信银行App的“银行卡超市”顺带申请自己喜欢的卡面。

3. 持有的**对应银行实体储蓄卡数量必须小于 4 张**：如果你已在同一银行持有4张或以上实体储蓄卡，该银行会因监管部门规定无法新开实体储蓄卡，请先注销多余的储蓄卡。

### 3.2 如何申请
考虑到绝大部分读者不在上海市，很多中行网点没有现成卡板、也没有开非预制卡的经验，**如果确实需要办理 Visa 储蓄卡，建议办理中信的卡。**

如你还是想办理中行的卡，在上海居住或近期有去上海的计划的读者可看“中行 - 上海分行网上申请”；不在上海且暂无去上海的计划的读者，请知晓：中行的「现场办卡」需要你当地网点有现成的跨境通卡卡板，卡面以卡种列表的前四种为主，但也可能会遇到莫奈卡和非人哉卡，都是预制卡；中行的「开立非预制卡」需要当地网点配合，尚在卡种列表的卡理论上都能办，办出来的都是非预制卡（卡背有印持卡人姓名），办卡进度需要自己打电话问。

无论选择哪家银行，**前往网点之前**，请记得携带你的身份证，如是学生且有学生证也最好带上（如果是准大学生，可携带录取通知书，以备不时之需）。

>在「晒卡」时，请务必给卡号、有效期（四位数字中间带斜杠的那个，比如「12/99」这种）、卡背的签名栏、持卡人拼音姓名（如有）打码或遮住！！否则如果因此被盗刷，责任在你，银行无责。

::: details 中信
1.申请。下载安装「中信银行」App，点击首页的「出国金融」，选择「Visa外币储蓄卡」，填写信息并提交。也可以搜索「银行卡超市」，再搜索「Visa」。

2.进度查询。在申请后1-2周内，在中信的App点「全部」，在账户管理板块找到「申卡记录查询」就可以查询，查询不用太频繁。三天一次就差不多了。

3.激活卡片。中信银行在制卡完成后会给你发EMS，记得留意收件（理论上会打电话告知，但部分地区不太负责的EMS快递员可能会直接放在收发室等）。**前往网点之前**，请记得携带你的身份证和新收到的银行卡，如是学生且有学生证也最好带上（如果是准大学生，可携带录取通知书，以备不时之需）。

工作人员会询问办卡用途，正常说出你的用途即可：海淘；在国外网站买东西，网站不支持银联卡，想办一张Visa的卡来在网站消费，你们中信有这种卡，所以就在你们App申请了一张。（如果你本来就有护照或者港澳通行证，也可以补充是想在旅行的时候使用）

在智能柜台激活的时候，可能会弹出是二类户的提醒，忽略即可，因为外币卡不分类。限额也不用管，限额只能限制人民币卡。

办卡后，工作人员可能会由于各种原因要求你注册一些东西，请注意：扫码领立减金和参与活动是可以的，你获得了优惠，也帮他们他们完成KPI；**开银行卡不需要开通证券账户，可以拒绝开通**。

**成功办理卡片后，请尽快执行[下文的「激活后、开始使用前」](#_4-激活后、开始使用前)中的操作。**

> 在「晒卡」时，请务必给卡号、有效期（四位数字中间带斜杠的那个，比如「12/99」这种）、卡背的签名栏、持卡人拼音姓名（如有）打码或遮住！！否则如果因此被盗刷，责任在你，银行无责。
:::

::: details 中行 - 现场办卡
请打电话，找有「跨境金融服务」的 网点，然后是找区/县支行、市分行、省分行。（微信搜索「中银留学GO」进入小程序，滑到最下面，点「境内跨境金融中心」，调整左上角的地区，即可查看你所在地级市和区/县的跨境金融中心网点）

## 4. 激活后、开始使用前
>在「晒卡」时，请务必给卡号、有效期（四位数字中间带斜杠的那个，比如「12/99」这种）、卡背的签名栏、持卡人拼音姓名（如有）打码或遮住！！否则如果因此被盗刷，责任在你，银行无责。
>{.is-warning}

请在开始使用前，务必完成以下操作。即使你暂时不使用，也请尽快在激活卡片后做以下操作！因为开卡后 6 个月内如果没有发生任何动账交易（**包括主动转账进卡**），会「非柜」（约等于锁卡），需要到网点解锁。
1. 在对应银行的App，绑定你的卡（如果没有自动出现），使用其他储蓄卡购汇（ [如何购汇？->跳转到购汇方法](#_5-2-购汇) ）后**向外币卡转账任意金额（建议：2美元）的外币**。完成后，2美元最好作为保底存款留着，避免长期（1年+）不使用被注销（长期不使用必须留一些余额，否则会被自动销卡），也给网站的小额扣款测试验证留点钱（海外网站在绑卡或消费时，有时会尝试冻结1美元或者1日元等等的小额资金，确保卡片有效）。
2. 在手机银行开通一些功能或者关闭境外锁。
- （中行的卡需要）开启 卡组织在线支付、卡组织代收、卡组织订购业务：账户管理 -> （点击你的跨境通卡，卡号为4或5开头） -> 支付设置 -> 跨行支付 -> 把上述三个开关开启
- （中行的卡需要）开启 小额/凭签名免密：账户管理 -> （点击你的跨境通卡，卡号为4或5开头） -> 限额设置 -> 小额/凭签名免密(POS消费) -> 设置一个合理的限额
- （中信的卡需要）关闭 境外交易锁： “账户”→选择中信Visa储蓄卡→“账户管理”→“智慧安全锁”→选择“关闭安全锁”
3. （可选但建议）开通微信交易提醒

中行的卡，自2023年某月起开始免费给跨境通卡客户发送交易提醒，但提醒只有时间和金额，只在款项冻结时发短信（在商户消费时，先冻结，过一段时间再扣帐），建议**关注 中国银行微银行 公众号，绑定跨境通卡，开启借记卡动账消息提醒。**

中信的卡不设免费短信交易提醒。

4. （可选）在卡背面的签名栏，用中性笔签名。理论上是要签的，但如果你不带这张卡出境到港澳台地区或国外，签的意义可能不大。

### 5.4 消费

「カード名義人」是持卡人，请用大写字母填上姓名的大写拼音，非预制卡（含中行、中信）以卡片背面为准，中行的预制卡请参考注释。

「有効期限」是有效期，请在卡片的背面寻找像是「12/99」一样的“xx/xx”的数字组合。「12/99」代表这张卡会于2099年12月过期（届时需要换卡）。有些网站比较「叛逆」，会显示20xx年xx月（跟卡面上的“月/年”反过来），记得别填错了。

「セキュリティコード」是安全码，也叫CVV2，请输入卡背的签名栏所印数字的后三位。

然后点击下一步，如果网站没有设置3D验证，会立刻冻结对应款项后提示付款成功。如果网站设置了3D验证，它会自动跳转到银行官方提供的网页，并发送验证码到预留手机号，请填写它来银行发送验证码后你输入到网页，以完成付款。

若新卡经常遇到付款失败等异常情况，请停止用卡3～5天。仅限部分开卡不足 3 天的新卡。具体原因不明。

若遇支付失败，请检查上述步骤和说明哪点没做到，如果确定自己都做到了，可在评论区反馈。

## E1  按需选读

### E1.1 扣款流程

与国际上大部分信用卡一样，采取**先预授权冻结、后入账扣款**的交易方式。即消费时不会立即扣款，而是先预授权（冻结）特定比例的资金，等待银行入账（=正式开始处理扣款）时再解冻+扣款，把钱正式转给商家。入账时间一般是商家发起正式扣款后的一至三天。需要注意的是，购买现货商品时，商家很多时候会立刻发起全额的预授权+正式扣款；购买尚未发售、接受预约的商品时，有些商家会先尝试小额扣款然后立刻取消（也可能在短时间内不取消，过段时间自动取消），验证卡片有效，发货前夕才会发起全额的预授权+正式扣款。（对应地，也有即使购买预约商品也立刻扣全款的商家）。

中行对非美元交易冻结102%，而中信对非美元交易冻结105%。

对于中行的卡，在手机银行上，如果账户存在预授权（冻结）资金，账户余额的下面会标有“（XXX 可用）”，账户余额减去括号中的数字即是目前累计的预授权金额；对于中信的卡，在手机银行上，默认显示的就是可用余额。

> **有关消费明细和通知的坑**：**手机银行无法查看未入账交易的详细情况**
>  手机银行只能直接/间接显示所有未入账交易总和的预授权金额，既不能单独显示每一笔未入账交易，也不能查询未入账交易的商户名、消费金额和消费时间等交易信息。如需查询未入账交易的交易商户、交易附言等详细信息，去人工柜台才可以查询到。

### E1.2 关于账户余额

**绑卡或者消费时， 美元账户可用余额，建议始终不少于 2 美元**
    在绑卡或者消费时为了验证卡片状态是否正常，网站一般先预授权（冻结）一笔小额资金（过一段时间后退还），测试成功后才发出正式的冻结请求给银行。
    测试金额一般为 **1 美元**，但可能存在以下情况使得不是 1 美元。一般来说，美元可用余额保持在 2 美元或以上，已足够应付大部分场合。
    ① **超过 1 美元**：如日区 Google Play 是 204 日元（折合超过1美元，不超过2美元）。
    ② **当地货币**：如日本亚马逊、Melonbooks等是 1 日元，德国 PayPal 是 1 欧元。


### E1.3 账户扣款顺序
中行的卡在对外支付场景支持19种外币的直付，中信的卡在对外支付场景支持8种外币的直付，上文已经提及具体币种。其余外币虽然可以存入，但不支持对外支付，只能用于境内柜台取现、境外ATM取现、跨境汇款等。**不支持自动购汇！**

**理论上的扣款顺序为：先扣交易币种账户（如有），再扣美元账户。
也就是说，交易币种如果余额不足或账户不存在的，自动使用美元。**

**注意：**

1. **非美元的外币账户只能支付对应币种**
    例如：日元账户只能支付日元，不能支付美元、港元等其他币种。
2. **指定币种以外的币种只能使用美元账户支付**（中行的卡实际上还支持使用英镑账户支付）

	例如：中信不支持韩元直付；两家银行都不支持新台币直付。
	再比如：使用中行的卡消费100新台币（折合约0.3美元），美元可用余额为0，但英镑可用余额为100英镑，会扣英镑，扣账成功。
	
3. 美元账户支付非美元，使用 VISA / MasterCard 卡组织汇率，银行汇率仅用于购汇和结汇。
   - 官方提供的汇率计算器： [VISA](https://www.visa.com.cn/travel-with-visa/exchange-rate-calculator.html)（官方计算器默认设定费率2%，改成0%！）、[MasterCard](https://www.mastercard.com.cn/zh-cn/personal/get-support/convert-currency.html)（Bank Fee写0）
   - 第三方汇率计算器： [VISA](https://www.kylc.com/huilv/i-visa.html)、[MasterCard](https://www.kylc.com/huilv/i-mastercard.html)
4. **不支持多账户支付**
    只能使用一个外币账户全额支付，不能从多个账户扣款。比如，想买一本220日元的电子书，日元余额为219日元，美元余额是1美元，这个时候是无法成功扣款的，因为日元和美元各自都不够钱。
    
### E1.4 3D验证服务

**3D验证服务**（*Verified by Visa*、*MasterCard SecureCode* 等) 是 VISA / MasterCard / 美国运通 等的卡组织验证持卡人的方式，常见于日本、香港地区等亚洲网站。若网站开启 3D 验证，购物网站会自动跳转到银行官方提供的网页，让你输入银行预留手机号，银行发送验证码后输入，以完成付款。遇到这种验证是正常的，只要确认网站正规，可以放心输入。（3D验证仅收集手机号和验证码，不收集其他信息）（如果手机信号不好或者家住境外，可能不方便接受到验证码短信。）

中行和中信的卡均完整支持3D验证。

### E1.5 帐单地址

两家银行的卡**不检验帐单地址**，所以与国内外标信用卡一样，不支持 AVS 系统验证——**购物网站一般不检测这个**，但一些云服务等商户可能要检验，遇到这种场景，中国大陆发的卡全部都不管用。
